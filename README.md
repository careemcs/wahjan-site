# Wahjan Agency Website

## تشغيل محلي
npm install
npm run dev

## بناء نسخة الإنتاج
npm run build   (الناتج في مجلد dist)

## الصور
صور المؤثرين والفريق داخل public/images بنفس الأسماء المكتوبة في src/App.tsx.

## محتوى لازم تراجعه قبل النشر (src/App.tsx)
- CLIENTS      : أسماء العملاء في الشريط المتحرك — تأكد إنهم عملاء فعليين ومسموح بعرضهم.
- CAMPAIGNS    : بيانات وأرقام الحملات حالياً أمثلة — استبدلها بحملات حقيقية معتمدة.
- SERVICES / TRACKS / EVENTS / PROCESS : نصوص مقترحة — عدّلها لتطابق خدماتكم الفعلية.
